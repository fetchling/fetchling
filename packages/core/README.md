# @fetchling/core

Embeddable core of [fetchling](https://www.npmjs.com/package/fetchling) — the
registry, namespacer, tool search, policy chain and router, as a plain
TypeScript library with no I/O, so a harness can `import { Router }` and skip
the network hop.

**Work in progress — not usable yet.** This version exports nothing useful.

Follow along: https://github.com/fetchling/fetchling
